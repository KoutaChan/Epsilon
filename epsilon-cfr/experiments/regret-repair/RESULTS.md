## 比較条件と完了範囲

| 条件 | 初回 REGRET の表現 | 専用 scalar baseline |
| --- | --- | --- |
| A | 従来の Nano 移植 | なし |
| B | 蒸留済み初期 AVERAGE の表現をコピー | なし |
| C | A と同じ | 状態・判断前履歴のみ、2 fold cross-fit |
| D | B と同じ | C と同じ方式 |

- 条件あたり2反復、各反復32,768局（REGRET 24,576、AVERAGE 8,192）。初回の既存データは全条件で共有し、2反復目は各条件の方策で新規収集しました。
- REGRET は各反復256更新、AVERAGE は2反復目の最後に256更新。batch 1,024、microbatch 512、BFLOAT16、MIXTURE 教師。その他の設定は README の固定値です。
- REGRET は32/64/128/256更新を独立 validation 4,096局で比較し、stochastic RM の局所値が最大の checkpoint を選びました。全候補まで学習しており、計算を途中で打ち切る早期停止ではありません。次反復には選択時点の重みと optimizer を一緒に継続しました。
- 主評価9モデルと追加評価4モデル、計13モデルを各8,192半荘で評価しました。各モデルで同じ未使用の2,048牌山を4席交替、固定 Nano 3人を相手とする greedy 対戦です。総対戦数は106,496半荘です。
- 別 seed の独立 score test は24,576局・377,397行。validation の選択には戻していません。
- 記録した82工程がすべて終了コード0で完了しました。最初の記録工程から最後の工程まで約83.2分で、GPU 2枚の並列処理、待ち時間、診断を含みます。

学習 seed は1本です。以下の95%信頼区間は、固定したモデルの評価誤差に対する探索的な正規近似であり、学習 seed 間のばらつきや多重比較を補正していません。

## 対戦結果

平均順位は小さいほど良い値です。初期モデルは **2.51660** でした。

| 条件 | 主評価：平均方策 AVG2 | 初回後悔学習後 σ2 | 追加評価：2回目の後悔学習後 σ3 |
| --- | ---: | ---: | ---: |
| A：従来 | 2.68469 | 3.72107 | 3.74097 |
| B：表現変更 | 2.68066 | 3.87854 | 3.91541 |
| C：baseline | 2.65625 | 3.77417 | 3.60205 |
| D：両方 | **2.56799** | 3.93201 | 3.83716 |

AVG2 は初期方策 σ1 と、実際に2反復目の収集へ使った σ2 を学習した平均方策です。σ3 はまだ収集しておらず、AVG2 に含まれません。σ3 の評価は、途中の教師診断を受けて追加した副次評価です。対戦結果で checkpoint を選び直していません。

順位差は左のモデルから右のモデルを引いた値で、負なら改善です。信頼区間は同じ4席分の牌山組を対応付けています。

| --- | ---: | ---: |
| A AVG2 − 初期 | +0.16809 | [+0.13646, +0.19972] |
| B AVG2 − 初期 | +0.16406 | [+0.13276, +0.19537] |
| C AVG2 − 初期 | +0.13965 | [+0.10794, +0.17135] |
| D AVG2 − 初期 | **+0.05139** | **[+0.02114, +0.08165]** |
| B AVG2 − A AVG2 | −0.00403 | [−0.03712, +0.02907] |
| C AVG2 − A AVG2 | −0.02844 | [−0.06072, +0.00383] |

D は A/B/C より良い一方、初期モデルとの差も残っています。初期モデルと同等、または初期より強く学習できたとは判断できません。B/C を単独で加えた平均方策の改善は、今回の A との区間では確認できませんでした。

平均方策の交互作用 `D − C − B + A` は −0.08423 [−0.12842, −0.04003] でした。これは checkpoint 選択、収集方策、収集データ、平均方策学習まで含む組合せの結果です。特定のネットワーク内部の相乗効果を単独で同定したものではありません。σ2 の greedy 成績が最悪の D で AVG2 が最良になる機序も、この比較だけでは確定しません。

σ3 は C が最良でしたが、平均順位3.60205で初期モデルに大きく劣ります。C/D は自身の σ2 より改善し、A/B は悪化しました。新しいデータ、累積 replay、追加更新、checkpoint 選択も同時に変わるため、この世代差を2反復目の baseline 単独の因果効果とは扱いません。

| B | +0.03687 | [+0.02570, +0.04803] |
| C | −0.17212 | [−0.19043, −0.15381] |
| D | −0.09485 | [−0.10500, −0.08469] |

σ3 の条件間比較では C − A が −0.13892、D − B が −0.07825でした。一方、σ3 の交互作用 `D − C − B + A` は +0.06067 [+0.03796, +0.08338] と悪化側です。平均方策で見られた併用効果を、次の RM 方策にも一般化できません。

## 未使用データでの後悔予測

初回で選択した σ2 を、初期方策 σ1 から新しく収集した24,576局・377,397行で検査しました。元の未補正教師を用い、stochastic/greedy RM の局所値 `τ·d` と、ゼロ予測に対する MSE 比を測っています。区間の独立単位は物理局です。

| 条件 | stochastic RM：平均 [95% CI] | greedy RM：平均 [95% CI] | MSE / ゼロ予測 [95% CI] |
| --- | --- | --- | --- |
| A | −0.001883 [−0.002331, −0.001436] | −0.002043 [−0.002685, −0.001402] | 1.000598 [1.000301, 1.000894] |
| B | −0.002105 [−0.002532, −0.001677] | −0.002176 [−0.002926, −0.001426] | 0.999314 [0.998444, 1.000185] |
| C | −0.002038 [−0.002502, −0.001575] | −0.001953 [−0.002598, −0.001308] | 1.001885 [1.001559, 1.002211] |
| D | −0.002666 [−0.003142, −0.002191] | −0.002786 [−0.003538, −0.002033] | 1.002650 [1.001913, 1.003388] |

全条件で stochastic/greedy の局所値は負でした。後悔予測から作る方策が、未使用データ上で望ましい方向へ変わっていない問題が残っています。MSE は A/C/D でゼロ予測より悪く、B では差を確認できませんでした。MSE の微小な改善だけを採用基準にはできません。

この score test は後続を σ1 に固定した1判断の尺度であり、半荘全体の強さと同じ指標ではありません。また σ3 の独立 score test は行っていません。

選択された REGRET 更新数は、反復1が A=32 / B=128 / C=32 / D=256、反復2の追加更新が A=256 / B=256 / C=128 / D=128 でした。反復2の validation は収集方策も変わるため、反復1との局所値の大小をそのまま汎化改善とは読めません。

## 専用 baseline の汎化

初回に学習した baseline を固定し、初回の学習用24,576局・376,392行に対して、自分が学習した fold と学習していない反対 fold を分けて再推論しました。独立 score test とは別の集合です。目的関数の重みは `w*h` を1回だけ適用しています。

| 初回 baseline の診断 | 補正後 / 補正前の教師二次モーメント | 変化 |
| --- | ---: | ---: |
| 自分の学習 fold | 0.624750 | −37.53% |
| 未学習の反対 fold（OOF） | 1.113960 | +11.40% |
| 独立 validation | 1.125864 | +12.59% |

学習データでは誤差が下がる一方、未学習の局では増えています。今回の状態表現・データ量・各 fold 256更新の組合せでは、baseline の過適合を確認しました。原因を更新数256だけに限定できる比較ではありません。

2反復目では、C の OOF 比が0.753459、D が0.769569となり、それぞれ24.65%・23.04%低下しました。validation でも C は0.752671、D は0.729702でした。ただし、σ2 が作る別の分布であり、初回の汎化問題が解決した証拠にはなりません。教師の二次モーメントを直接測った値であって、条件付きの雑音分散そのものでもありません。

## 実行速度と追加費用

実行機は Radeon RX 7900 XTX 24 GiB ×2、既存の ROCm / DJL 実行環境です。Collector は2反復目の32,768局を、REGRET と AVERAGE の収集・圧縮保存時間の合計で割っています。ここでの「局」は半荘ではありません。

Learner は sampling と学習、および同期を伴う checkpoint 保存を含む進捗時間による samples/s です。replay・モデルの初期ロードは learner 速度の計測対象外ですが、工程全体の時間には含みます。括弧内は batch 内の重複を除いた実処理件数/sであり、独立した新規局数/sではありません。

## 実装と検証

Nano の既存特徴表現を使う状態表現と optimizer 管理を共通化し、専用 baseline はその構成を再利用しています。REGRET/AVERAGE の役割と、比較 runner / 選択 / 評価を分離しました。Q、Oracle、未選択行動の環境分岐は追加していません。

- 基準コミット `edcc748` を先に作成し、比較実装 `baab5b7`、既定初期化の維持・汎化診断 `ce605be`、副次評価 `2afa403` を別コミットにしました。
- 全モジュール test-compile、CFR のローカル単体テスト74件、共通 device テスト2件、サーバー native テスト28件、追加の汎化診断テスト4件を通過しました。比較 runner テスト7件、Python テスト21件も通過しています。これらは重複する検査集合を含むため、合計件数にはまとめません。
- Java formatter と Python Ruff を適用しました。
- 既存 checkpoint の64観測について、共有部抽出前後の raw score は完全一致しました。
- 実データの GPU smoke で、baseline の学習、保存・復元、optimizer 継続を検査しました。復元直後の予測は一致し、継続後の最大差は0.0001221で検査許容値0.0002以内でした。
- 関係のない Tenhou の作業中変更はコミット対象から除外しました。
